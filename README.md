# 群内双色球统计与战报生成 HTML 工具

本项目是本地运行的 HTML 单页工具。用户上传历史 Excel，粘贴今日投注，
输入开奖号码后，工具在浏览器本地完成解析、中奖计算、奖池和排行榜更新，
并生成新的 Excel 文件和可复制到群里的今日战报。

玩法、中奖、奖金和奖池规则集中记录在 [rules.md](./rules.md)。

如需处理旧数据，可以在页面填写“当前奖池补充值”。该值为空时按 `0`
处理；填写后，本次计算使用的奖池金额 = Excel 最新奖池余额 + 补充值。

导出的 Excel 使用中文 sheet 名、中文列名和中文内容；旧英文 sheet 的历史
Excel 仍可导入用于迁移。

## 开发运行

```bash
npm install
npm run dev
```


## 投注文本

页面上的日期和期次是联动的。用户选择日期后，期次会自动按 `YYYYMMDD`
格式生成，例如 `2026-05-10` 会生成 `20260510`。

开奖号码支持手动输入，也可以点击页面上的“随机生成开奖号码”按钮自动填入。
静态浏览器页面无法直接执行本机 Python；如需用 Python `secrets` 库生成同规则
号码，可运行：

```bash
uv run --python 3.12 scripts/generate-winning-numbers.py
```

也可以改用已安装的 3.14：

```bash
uv run --python 3.14 scripts/generate-winning-numbers.py
```

每行一条投注记录，包含昵称、6 个红球和 1 个蓝球。支持空格、英文逗号、
中文逗号、竖线及其常见组合。

示例：

```text
张三 01 02 03 04 05 06 | 07
李四，01，03，04，05，07，09，02
王五 01 02 03 04 05 06 - 07
1 张三 01 02 03 04 05 06 - 07
2 张三（帅哥） 01 02 03 04 05 06 - 07
3 李四(hero) 01 02 03 04 05 06 - 08
```

红球范围为 01-09 且必须 6 个不重复号码，蓝球范围为 01-08。手动输入时
`1` 和 `01` 都可识别；系统输出统一使用两位数格式。格式错误会显示具体
行号和原因。

同一个人当天第一次投注会自动向奖池加入 2 Hao币。第二次投注从账户扣
3 Hao币，第三次投注从账户扣 4 Hao币，并加入奖池。每人每天最多买
三注；第四注起为无效投注且不加入奖池。余额不足时该投注为无效投注。红球
重复、红蓝球越界、号码数量缺失也统一为无效投注，但仍按第一次或后续投注
规则向奖池增加 Hao币或尝试从账户扣除。
